# Kursmaterial

Alles, was Du im Kurs liest und brauchst, liegt in diesem Ordner, Du brauchst also nie
eine Website. Öffne die Datei für den Block, in dem Du gerade bist.

Jede Übung ist eine Aufgabenkarte: Ziel, Material, Rahmen, Fertig-Kriterium. Den Prompt
schreibst Du selbst. Woran Du ihn prüfst, steht in `prompt-rubrik.md`.
