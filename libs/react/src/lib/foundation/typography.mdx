# Typography

The design system uses three typefaces, all loaded via Google Fonts: **Instrument Sans** for UI text,
**Instrument Serif** for display headings, and **JetBrains Mono** for code, tokens, and prop names.

```css
font-family: var(--ui-font-family);  /* Instrument Sans — UI */
font-family: var(--ui-font-display); /* Instrument Serif — display */
font-family: var(--ui-font-mono);    /* JetBrains Mono — code */
```

## Family Tokens

| Token | Family | Used for |
|---|---|---|
| `--ui-font-family` | Instrument Sans | body copy, labels, controls |
| `--ui-font-display` | Instrument Serif | display headings |
| `--ui-font-mono` | JetBrains Mono | code samples, token names, kbd chips |
