# Architecture Decision Records

Each record uses MADR-style YAML frontmatter, so its `status`, `sources` (and `confidence`, on the reconstructed 0001–0016) are machine-readable.

**0001–0016 are RECONSTRUCTED** — written after the fact from the repo, commit history, and session notes, not recorded when each decision was made; each carries a per-record **Confidence** marker (_Documented_ = quoted from existing repo text, _Reconstructed_ = inferred from commits/code/session). **From 0017 onward, ADRs are recorded at decision time** per the `CLAUDE.md` § Decision Records convention — those are contemporaneous and carry no `confidence` field (shown as _Recorded_ below).
