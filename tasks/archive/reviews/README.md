# Archived review documents

These are the standalone review, audit and triage documents that used to sit in `tasks/`
(course and docs reviews, gate, spec, Figma, a11y, Storybook and uianatomy reviews).
They are frozen as of 2026-10-11: read them for evidence and history, do not edit them.

Open findings live in [`tasks/reviews.md`](../../reviews.md), the single tracker for review
findings. The verdict of every row in these documents (KEEP, DONE, OBSOLETE-CDS, and so on) is
in [`../review-triage-2026-10-11.md`](../review-triage-2026-10-11.md).

New findings from a review go into `tasks/reviews.md` as new `R-NNN` items, not into a new
review file here.
