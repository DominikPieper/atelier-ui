# Handouts

Printed handouts for the two-day course, one copy per participant. Each is one page, plain Markdown, and carries everything it needs: the docs site is password-protected and participants cannot open it, so a handout names no page and no URL (owner, 2026-11-19).

- [`ds-scorecard.md`](ds-scorecard.md): what a design system has to bring, seven rows to mark yes / partly / no
- [`figma-readiness-checklist.md`](figma-readiness-checklist.md): the checks of the Figma file as tick boxes
- [`storybook-readiness-checklist.md`](storybook-readiness-checklist.md): the checks and the read-only self-check of your Storybook as tick boxes
- [`ladder-card.md`](ladder-card.md): the five tools the agent checks itself with, by stage, with what each one cannot see
- [`rescue-sheet.md`](rescue-sheet.md): what to do when the seat is red, step by step
